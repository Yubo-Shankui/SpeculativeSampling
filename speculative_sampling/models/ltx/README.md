# LTX integration

This directory contains the LTX retained-KV/ReRoPE integration, including
native state transactions, output mapping, split-service coordination, decoder
state, recovery, and diagnostics.

The implementation is public for study and extension, but it is still being
tuned. Deployment configs, checkpoint-specific launch instructions, and a
supported runnable release will follow after validation. Use H3 for the current
end-to-end demo.
